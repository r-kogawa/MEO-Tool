## 1. 目的

- 店舗の来店客にアンケートへ回答してもらい、満足度の高い顧客の Google 口コミ投稿を後押しする
- 口コミ文面の作成負担を下げるため、アンケート回答内容をもとに文章の下書きを生成する
- 店舗運営者が Google マップ上の検索順位を定点観測できるようにする
- 個人事業主と法人（複数店舗・複数担当者）の両方が、自分の Google ビジネスプロフィールと連携して使えるようにする

## 2. 要件（受領分）

| ID | 要件 | 対応する機能（`04-features.md`） |
| --- | --- | --- |
| R-1 | 口コミアンケートフォームに回答してもらい、**特定の条件を満たした場合のみ** Google の口コミ入力へ遷移する | F-10, F-11, F-13 |
| R-2 | Google 口コミの入力内容は**文章を生成**したうえで Google 側へページ遷移する | F-08, F-12, F-13 |
| R-3 | 管理画面で**アンケートフォームの作成**と**公開管理**ができる | F-06, F-07, F-08, F-09 |
| R-4 | 管理画面で**検索順位を検索・表示**できる | F-15, F-16, F-17 |
| R-5 | **個人・法人単位**で管理し、それぞれが管理する Google Business と連携する前提で**管理画面を出しわける** | F-01〜F-05, F-02 |

> ⚠️ R-1 / R-2 は Google の口コミポリシー、および日本の景品表示法（ステルスマーケティング規制）に抵触するおそれがあります。
> 仕様確定前に必ず `05-open-issues.md` の **I-01 / I-02 / I-03** を確認してください。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 組織（Organization） | 契約・管理の単位。`type` が `individual`（個人）または `corporate`（法人） |
| メンバー | 組織に所属するログインユーザー。ロールは `owner` / `admin` / `staff` |
| 店舗（Store） | 組織が管理する実店舗。GBP のロケーション 1 件と対応する |
| GBP | Google Business Profile（旧 Google マイビジネス） |
| Google 連携（Connection） | 組織が OAuth で許可した Google アカウントと、その権限で見える GBP アカウント |
| アンケート（Survey） | 店舗に紐づく回答フォーム。下書き → 公開 → 停止 の状態を持つ |
| 遷移条件（Redirect Rule） | 回答内容から「Google 口コミ導線を出すか」を判定するルール |
| 口コミ下書き（Review Draft） | 回答内容をもとに LLM で生成した口コミ文面。回答者が編集してから使う |
| 順位計測（Rank Check） | キーワード × 地点ごとに、Google マップ検索で店舗が何位に表示されるかを取得する処理 |
| 回答者 | アンケートに答える来店客。ログインしない |

## 4. 前提（仮置き）

要件に明記がないため、以下の前提で設計しています。違う場合は `05-open-issues.md` の該当項目で指摘してください。

| # | 前提 | 関連する未決事項 |
| --- | --- | --- |
| P-1 | 技術スタックは既存リポジトリに合わせ、Nuxt 4 + Tailwind v4 + Firebase（Hosting / Auth / Firestore / Functions）とする | I-20 |
| P-2 | 管理画面・回答画面とも SPA（`ssr: false`）で静的配信し、サーバー処理は Cloud Functions に集約する | I-20 |
| P-3 | 1 人のユーザーが複数の組織に所属できる（代理店・本部担当を想定） | I-14 |
| P-4 | 個人組織はメンバー 1 名（owner のみ）。メンバー管理画面は法人のみ表示する | I-13 |
| P-5 | アンケートは店舗単位で作成し、1 店舗に複数アンケートを持てる | I-08 |
| P-6 | 遷移条件の判定と口コミ文章の生成はサーバー側で行う（クライアントに条件式を渡さない） | — |
| P-7 | Google の口コミ投稿 URL には本文を渡せないため、生成文は**クリップボードにコピー**してから遷移する | I-04 |
| P-8 | 運営側（自社）がすべての組織を横断して見る「運営管理画面」を別に設ける | I-15 |
